# Giuseppe Lanna - Resume

Esse repositório é feito para automatizar a geração do meu currículo em diferentes idiomas.

- [PT-BR](https://cv-giuseppe-lanna.s3.us-east-1.amazonaws.com/pt-br.pdf)
- [EN-US](https://cv-giuseppe-lanna.s3.us-east-1.amazonaws.com/en-us.pdf)


## Fluxo:
- Escrevo uma versão em .MD
- Mando a IA gerar em quantas outras eu quiser
- Dou push
- O Workflow gera os PDFs
- Assume uma role no meu AWS
- Faz upload dos PDFs para um bucket S3 público
